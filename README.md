## 1. Талаптар және жоспар
- **Не бақылаймын және неге:** Күнделікті ұйқы уақытымның ұзақтығын (минутпен) және түнде ояну санын бақылаймын. Бұл сабақ үлгерімі мен оқу күндеріндегі шаршаңқылықтың ұйқы сапасына қалай байланысты екенін түсіну үшін қажет.
- **Бір жазбада сақталатын мәліметтер (өрістер, түрлері, шектеулері):**
   - `date` (String) — күні («КК.АА» форматында, бос емес);
   - `dayType` (String) — күн түрі («оқу күні», «демалыс», бос емес);
   - `sleepMinutes` (int) — ұйқы ұзақтығы минутпен (0..1440);
   - `wakeUps` (int) — түнде ояну саны (0..20).
- **Бағдарлама не істейді (мәзір пункттері):**
   - 1: Барлық жазбаларды шығару;
   - 2: Жазбалар санын, жалпы ұйқы қосындысын және орташа мәнін есептеу;
   - 3: Ең ұзақ ұйықтаған күнді табу;
   - 4: Ереже бойынша ұйқысы 420 минуттан (7 сағаттан) кем емес күндерді санау;
   - 5: Күн түрі бойынша сүзу («оқу күні» / «демалыс»);
   - 6: Өз функциям (орташадан ұзақ ұйқы);
   - 0: Шығу.
- **Өз функциям (6-пункт):** `printAboveAverage()` — орташа ұйқы ұзақтығынан ұзақ ұйықтаған күндерді шығарады. Қай күндері дененің толық тынығып үлгергенін бағалауға мүмкіндік береді.

## 3. Деректерді қалай жинадым
Деректер екі апта бойы күнделікті ұйықтар алдында және таңертең оянғанда телефонның оятқышы (будильник) мен таймері арқылы тіркеліп отырды[cite: 2]. Жату және тұру уақыттарының арасындағы нақты минуттар есептеліп енгізілді.

Мен үнемі сабақ ерте болмаған күндері ұйықтар алдында будильникті 8 сағатқа, кей кездері 7 сағатқа қойып, ұйқы режимін сақтауға тырысамын. Дегенмен, соңғы кездері сабақты күндіз оқудың орнына түнде оқып, ұйқы режимім біршама бұзылды (мысалы, 13.10 және 15.10 күндері кеш жатып, ұйқы ұзақтығы 420 минуттан аз болды). Дәлел ретінде телефон экранынан бірнеше скриншот сақталып, `evidence/` қалтасына салынды[cite: 2].
